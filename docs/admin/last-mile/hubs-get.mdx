---
title: "Obtener un hub"
openapi: get /admin/last-mile/hubs/{hubId}
---

Devuelve un hub de tu cuenta. El `hubId` puede ser el ID de Justo o tu `externalId`.

La respuesta incluye la dirección con las coordenadas que Justo usa para calcular las rutas y los precios. Revísalas después de crear un hub con una dirección sin coordenadas para confirmar que quedó bien ubicado.
