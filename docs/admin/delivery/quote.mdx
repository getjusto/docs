---
title: "Cotizar entrega sin pedido"
openapi: post /admin/deliveries/quote
---

Cotiza una entrega sin pedido antes de crearla. Envía un local autorizado en `storeId` y las direcciones en `fromAddress` y `toAddress`, con `streetAddress` y `countryCode`. API resuelve los identificadores de lugar internamente.

`tipAmount` agrega la propina a `priceWithTax` para calcular `totalAmount`. Usa el mismo monto de propina al crear el despacho.

Esta operación no crea entregas ni reserva el precio. Para obtener además coordenadas y ruta, usa [Consultar cotización y ruta](/docs/admin/delivery/preview).
