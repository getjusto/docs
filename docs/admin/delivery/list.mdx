Lista las entregas sin pedido creadas para la marca y los locales autorizados. Una entrega sin pedido es un despacho de Justo Delivery que no tiene asociado un pedido de Justo Ecommerce; se crea directamente desde Justo Admin, API o una integración externa cuando la marca necesita mover un pedido tomado fuera de Justo o coordinar un despacho manual.

La respuesta viene paginada. Permite buscar por código o `externalId`.

Por defecto excluye entregas en curso. Envía `includeActive=true` para incluirlas.
